# KNSCL DESIGN DIRECTION

## Purpose

This document is the visual and UX design authority for the KNSCL platform.

KNSCL should feel like a **real, established football competition and sports media platform**, not a generic AI-generated website, SaaS dashboard, admin template, or collection of UI components.

Every future interface decision should be evaluated against this document.

---

# 1. THE CORE DESIGN IDEA

## KNSCL should feel like:

**Football first.
People first.
Competition first.
Information second.
Technology in the background.**

The website should communicate the energy and authenticity of Kenyan football while maintaining the professionalism expected from a serious national football competition.

The design should feel:

* Confident
* Editorial
* Sporting
* Energetic
* Authentic
* Local
* Human
* Professional
* Contemporary
* Purposeful

It should NOT feel:

* Corporate
* Generic
* Over-engineered
* SaaS-like
* Template-driven
* Artificial
* Over-decorated
* "AI-designed"

---

# 2. PRIMARY DESIGN REFERENCE

Use the world's best football and sports platforms as **design references**, not templates.

Study how professional football platforms handle:

* Matchday storytelling
* Fixtures
* Results
* League tables
* Club identity
* Player identity
* News
* Photography
* Typography
* Navigation
* Competition hierarchy
* Editorial content

FC Barcelona may be used as one reference point for:

* Strong football identity
* Editorial storytelling
* Match presentation
* Visual hierarchy
* Content structure
* Competition presentation

However:

**Never copy FC Barcelona's visual identity.**

Do not reproduce its:

* Layouts
* Branding
* Logo
* Colour system
* Typography
* Components
* Imagery
* Exact interactions

Extract principles and reinterpret them for KNSCL.

---

# 3. KNSCL MUST HAVE ITS OWN VISUAL IDENTITY

Do not design KNSCL as:

> "FC Barcelona but Kenyan."

KNSCL should instead feel like a **distinct Kenyan football ecosystem**.

The design should communicate:

* Kenyan football
* Local communities
* Young players
* Competition
* Grassroots football
* County identity
* Clubs
* Supporters
* Matchday culture
* Ambition

Authenticity is more important than attempting to look expensive.

---

# 4. DESIGN PHILOSOPHY

Follow this hierarchy:

### 01 — Information Architecture

Make the information easy to understand.

### 02 — User Flow

Make it obvious where the user should go next.

### 03 — Content Hierarchy

Make important information visually dominant.

### 04 — Typography

Use typography to create personality and hierarchy.

### 05 — Composition

Create interesting and intentional layouts.

### 06 — Imagery

Use photography to create emotional connection.

### 07 — Components

Create components that support the experience.

### 08 — Motion

Use animation only when it improves understanding.

### 09 — Decoration

Decoration is optional and should never compensate for weak design.

---

# 5. THE ANTI-AI-SLOP RULE

The following patterns should be treated as design warnings.

Avoid excessive use of:

* Rounded cards
* Glassmorphism
* Gradient backgrounds
* Gradient text
* Floating blobs
* Excessive shadows
* Excessive pills
* Excessive badges
* Generic icon grids
* Huge empty hero sections
* Repetitive three-column card layouts
* Dashboard-style grids
* Excessive border radii
* Decorative lines
* Random geometric shapes
* Unnecessary animations
* Floating UI elements
* Generic stock illustrations
* Generic SaaS imagery
* "Everything is a card"

Do not add these simply because they make a design appear more sophisticated.

### Critical rule:

**If removing a visual effect makes the interface clearer, remove it.**

---

# 6. COMPOSITION

Do not make every section follow the same visual structure.

Avoid:

```text
Heading
Subtitle

[ Card ] [ Card ] [ Card ]

[ Card ] [ Card ] [ Card ]
```

repeated throughout the website.

Instead, use varied editorial composition.

Possible patterns include:

* Large feature + supporting stories
* Large match + compact match list
* Split layouts
* Full-width editorial sections
* Asymmetric grids
* Large typography + supporting information
* Dense statistical sections
* Image-led stories
* Horizontal content rails
* Full-width competition banners
* Strong visual transitions between sections

The layout should have **rhythm**.

A user should be able to visually distinguish one section from another without relying on coloured cards.

---

# 7. THE HOMEPAGE SHOULD TELL A STORY

The homepage is not a component gallery.

It should behave like an editorial football experience.

The exact order should be determined through UX analysis, but the general narrative should move from:

**WHO WE ARE**

↓

**WHAT IS HAPPENING**

↓

**NEXT MATCH / MATCHDAY**

↓

**COMPETITION**

↓

**CLUBS & PLAYERS**

↓

**STORIES**

↓

**DISCOVER MORE**

Every section should answer a user need.

Do not add sections simply because there is empty space.

---

# 8. MATCHDAY IS THE HEART OF THE EXPERIENCE

Football is the primary product.

Match information should therefore receive strong visual treatment.

Users should be able to understand immediately:

* Who is playing?
* When?
* Where?
* What competition?
* What was the result?
* What is the match status?

Scores should be visually prominent.

Team names should be easy to scan.

Venue and kickoff information should be secondary but accessible.

The match interface should feel like a football product, not a database table.

---

# 9. TYPOGRAPHY

Typography should be one of the strongest elements of the visual identity.

Do not rely on oversized headings alone to create hierarchy.

Establish a deliberate typographic system for:

* Display headings
* Section headings
* Navigation
* Match scores
* Team names
* Player names
* League positions
* Statistics
* News headlines
* Supporting text
* Metadata

Football scores and numerical information should have particularly strong visual clarity.

Typography should feel:

**Bold + editorial + modern + confident**

Avoid:

* Too many font families
* Excessive font weights
* Random uppercase text
* Poor line lengths
* Weak heading hierarchy
* Tiny metadata everywhere

---

# 10. IMAGERY

Photography should play an important role in KNSCL's identity.

Prefer authentic football imagery over generic stock imagery.

Ideal imagery includes:

* Kenyan players
* Local football grounds
* Matchday action
* Supporters
* Coaches
* Youth football
* Clubs
* Community football
* Celebrations
* Training
* Local football culture

Images should feel:

**Documentary, energetic, human and authentic.**

Avoid images that feel like generic corporate sports advertising.

Do not add images merely to fill space.

---

# 11. COLOUR

Use colour strategically.

The interface should have:

### Primary brand colour

The dominant KNSCL identity.

### Supporting colours

Used to create hierarchy and distinguish important states.

### Neutral system

Backgrounds, text, borders and supporting surfaces.

Colour should communicate:

* Brand
* Competition
* Match state
* Success
* Warning
* Important information

Do not use multiple bright colours simply to make the interface "pop."

---

# 12. CARDS

Cards are a tool, not a design language.

Use cards when content genuinely benefits from being grouped or separated.

Do not put every section inside a card.

Good candidates for cards:

* Individual matches
* News stories
* Clubs
* Players
* Important statistics

Poor candidates:

* Entire page sections
* Navigation
* Every paragraph
* Every statistic
* Every heading

Prefer **open layouts** when grouping is unnecessary.

---

# 13. BORDER RADIUS

Use a restrained radius system.

Avoid:

> Everything is extremely rounded.

The interface should feel mature and sporting rather than playful SaaS.

Use sharper or moderately rounded geometry where appropriate.

Consistency matters more than excessive softness.

---

# 14. DEPTH & SHADOW

Depth should be subtle.

Do not use large floating shadows around every element.

Prefer hierarchy through:

* Contrast
* Spacing
* Typography
* Scale
* Background changes
* Borders
* Imagery

Shadows should communicate elevation when elevation actually exists.

---

# 15. NAVIGATION

Navigation should prioritise the things football fans actually care about.

Primary destinations should focus on:

* Fixtures
* Results
* League Table
* Clubs
* Players
* News

Avoid unnecessarily complicated navigation.

Navigation should remain predictable across the website.

---

# 16. INFORMATION DENSITY

Do not confuse premium design with excessive whitespace.

Football platforms contain information.

The goal is:

**High information value + strong hierarchy + comfortable readability.**

A good interface should allow users to scan quickly.

Use:

* Grouping
* Typography
* Alignment
* Spacing
* Dividers
* Position
* Contrast

to control density.

---

# 17. RESPONSIVE DESIGN

Mobile is not a smaller desktop.

On mobile:

* Prioritise match information.
* Prioritise scores.
* Prioritise important headlines.
* Simplify navigation.
* Reorder content where necessary.
* Reduce unnecessary metadata.
* Avoid horizontal overflow.
* Preserve visual hierarchy.

The mobile experience should feel deliberately designed.

---

# 18. MOTION

Motion should communicate meaning.

Good uses:

* Page transitions
* Match status changes
* Navigation transitions
* Hover feedback
* Loading states
* Content reveal

Avoid:

* Constant movement
* Excessive parallax
* Decorative animations
* Animating every card
* Slow transitions that make the website feel sluggish

Motion should support the football experience, not compete with it.

---

# 19. COMPONENT PHILOSOPHY

Components should be designed around real football concepts.

Examples:

* Match Card
* Match Hero
* Fixture List
* Result
* League Table
* Club Identity
* Player Profile
* Player Statistics
* News Story
* Competition Header
* Matchday Header

Do not create generic components first and force football content into them.

Start with the user's information needs.

---

# 20. VISUAL RHYTHM

The website should have rhythm.

Alternate between:

* Dense information
* Spacious moments
* Large imagery
* Strong typography
* Match information
* Editorial storytelling
* Statistical information

Do not make every section visually identical.

The user's eye should naturally move through the page.

---

# 21. ACCESSIBILITY

Visual quality must not compromise usability.

Maintain:

* Strong contrast
* Readable typography
* Clear focus states
* Keyboard accessibility
* Meaningful labels
* Touch-friendly controls
* Logical information hierarchy

A beautiful interface that is difficult to use is not good design.

---

# 22. DESIGN DECISION TEST

Before introducing any UI element, ask:

### Does it improve understanding?

### Does it improve navigation?

### Does it improve hierarchy?

### Does it communicate football identity?

### Does it improve usability?

### Does it create emotional connection?

If the answer is no:

**Do not add it.**

---

# 23. THE "REMOVE BEFORE ADDING" RULE

When improving an existing page:

**First remove what is unnecessary.**

Then:

**Reorganise what remains.**

Then:

**Improve typography and spacing.**

Then:

**Improve composition.**

Then:

**Introduce imagery and visual storytelling.**

Only after that should additional decoration be considered.

---

# 24. THE FINAL QUALITY BAR

The final KNSCL experience should make someone think:

> "This is a serious football platform."

Not:

> "This is a nice AI-generated website."

The design should feel like it has been deliberately art-directed.

Every major visual decision should have a reason.

Every section should have a purpose.

Every component should belong to the same visual world.

---

# 25. NON-NEGOTIABLE PRINCIPLE

## DO NOT DESIGN A TEMPLATE.

## DESIGN KNSCL.

The objective is not to make the website look like every other modern website.

The objective is to create a **recognisable KNSCL digital identity** that can eventually extend across:

* Website
* Mobile experience
* Social media
* Match graphics
* Club profiles
* Player profiles
* News
* Matchday communication
* Digital campaigns

The website is the beginning of the KNSCL visual ecosystem, not an isolated interface.
