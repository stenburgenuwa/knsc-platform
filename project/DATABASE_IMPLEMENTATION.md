### 2. Database Indexes

- **Primary Keys:** All tables use UUID (Version 4) for global uniqueness
- **Foreign Keys:** Enforced referential integrity on all relationships
- **Search Indexes:** On all frequently queried columns
- **Unique Constraints:** On registration numbers, emails, codes, slugs
- **Compound Indexes:** On common query patterns (userId + roleId, clubId + seasonId, etc.)

### 3. Database Constraints

- **NOT NULL:** Mandatory fields explicitly marked
- **UNIQUE:** Email, phone, player number, referee number, invoice number, etc.
- **Check Constraints:** Via Prisma schema validation
- **Soft Deletes:** deletedAt timestamp on operational entities
- **Cascade Delete:** On child records when parent deleted
- **Referential Integrity:** All foreign keys enforced

### 4. Migrations

- **001_initial_schema.sql:** Creates PostgreSQL extensions (uuid, pg_trgm, unaccent)
- Auto-generated by `prisma migrate dev` command
- All migrations are reversible
